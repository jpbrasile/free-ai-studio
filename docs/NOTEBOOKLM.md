# NotebookLM — complément gratuit pour les documents et l'apprentissage

NotebookLM est proposé comme **service complémentaire externe** à Free AI Studio.

Il est particulièrement adapté à l'étude de sources : documents, PDF, pages Web, vidéos YouTube, audio et autres contenus pris en charge par Google.

## Pourquoi l'ajouter

Free AI Studio reste l'outil généraliste :

- chat et vision ;
- recherche Web ;
- image et vidéo ;
- voix ;
- code ;
- modèles gratuits et Boost ponctuel.

NotebookLM complète surtout la partie :

- questions/réponses ancrées dans les sources avec citations ;
- synthèse de documents ;
- guides d'étude et rapports ;
- cartes mentales ;
- quiz et flashcards ;
- résumés audio/vidéo et autres artefacts disponibles selon l'offre Google.

## Accès

Dans Free AI Studio, ouvrir :

```text
http://127.0.0.1:8010/notebooklm
```

ou directement :

```text
https://notebooklm.google.com/
```

## Gratuit ne signifie pas illimité

NotebookLM possède un niveau gratuit avec des quotas. Google peut modifier les fonctionnalités et limites.

Free AI Studio ne doit donc **jamais coder en dur une promesse d'illimité** dans son interface.

L'assistant de code doit vérifier la documentation officielle Google avant de mettre à jour les chiffres de quota.

## Confidentialité et séparation

Dans cette version, NotebookLM n'est pas intégré par une API non officielle.

Le bouton ouvre simplement le service officiel Google :

- aucune clé Free AI Studio n'est transmise ;
- aucun document n'est envoyé automatiquement ;
- aucune automatisation fragile du site NotebookLM n'est utilisée.

Cette séparation garde l'installation simple et évite de dépendre d'une interface Web non documentée.
