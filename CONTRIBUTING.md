# Contribuer à Free AI Studio

Merci de contribuer.

## Avant toute modification

1. Lire `AGENTS.md`.
2. Conserver le mode gratuit uniquement par défaut.
3. Ne jamais ajouter de secret au dépôt.
4. Pour une API, un modèle, un quota ou un prix : vérifier une source officielle actuelle.
5. Préserver l'expérience débutant.

## Règles de contribution

- petites PR ciblées ;
- expliquer le problème et le bénéfice utilisateur ;
- ajouter ou mettre à jour la documentation ;
- tester les scripts concernés ;
- ne jamais activer un service payant automatiquement.

## Checklist PR

```text
[ ] Aucun secret
[ ] FREE_ONLY reste vrai par défaut
[ ] ALLOW_PAID_MODELS reste false par défaut
[ ] ALLOW_PAID_GPU reste false par défaut
[ ] Documentation mise à jour
[ ] Tests/syntaxe OK
[ ] Parcours débutant préservé
```
